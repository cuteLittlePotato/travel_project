# 云游坊 - 交互原型说明

## 项目概述

本原型基于 `docs/requirements.md` 需求文档设计，使用纯 HTML/CSS/JavaScript 实现，展示了云游坊旅游推荐与规划系统的核心交互流程。

## 目录结构

```
prototype/
├── index.html              # 原型入口页
├── css/
│   └── common.css         # 通用样式
├── js/
│   ├── common.js          # 通用工具函数
│   └── mockData.js        # 模拟数据
├── c-end/                 # C端用户页面
│   ├── home.html          # 首页
│   ├── attraction-detail.html  # 景点详情
│   ├── chat.html          # 智能对话
│   ├── plans.html         # 旅游计划管理
│   └── footprints.html    # 足迹管理
└── b-end/                 # B端管理后台
    ├── dashboard.html     # 数据看板
    ├── attractions.html   # 景点管理
    └── users.html         # 用户管理
```

## 快速开始

### 方式一：直接打开

1. 在浏览器中打开 `prototype/index.html`
2. 选择进入 C 端或 B 端

### 方式二：本地服务器（推荐）

```bash
# 使用 Python
cd prototype
python -m http.server 8000

# 或使用 Node.js http-server
npx http-server -p 8000
```

然后访问：http://localhost:8000

## 功能说明

### C 端功能（用户端）

#### 1. 首页（home.html）
- **热度排行**：展示按热度排序的景点列表
- **分类浏览**：支持按类型（历史人文、自然景色）和地区筛选
- **搜索功能**：支持关键词搜索景点
- **景点卡片**：悬停显示详细信息，点击进入详情页

#### 2. 景点详情（attraction-detail.html）
- 景点完整信息展示（图片、简介、门票、开放时间等）
- 快速操作：加入计划、标记足迹、咨询助手
- 游览建议和最佳季节推荐

#### 3. 智能对话（chat.html）
- 模拟 LLM 对话交互
- 快速操作按钮（预设常见问题）
- 支持多轮对话
- 智能回复（根据关键词匹配）
- 支持从景点详情页跳转并携带上下文

#### 4. 旅游计划（plans.html）
- 计划状态管理：规划中、待进行、进行中、已完成
- 新建计划表单（目的地、日期、预算）
- 状态流转：确认计划、标记完成、取消计划
- 编辑和删除功能

#### 5. 足迹管理（footprints.html）
- 展示去过的景点
- 统计数据：景点数、省份数、城市数、照片数
- 添加足迹：选择景点、评分、撰写游记
- 区分自动生成和手动添加

### B 端功能（管理后台）

#### 1. 数据看板（dashboard.html）
- 核心指标卡片：总用户数、活跃用户、计划数、完成率
- 用户增长趋势图（占位符）
- 热门景点排行榜
- 热门目的地统计
- 内容统计概览

#### 2. 景点管理（attractions.html）
- 景点列表展示（分页）
- 搜索和分类过滤
- 添加景点：完整表单（名称、位置、分类、价格、热度等）
- 编辑景点信息
- 删除景点

#### 3. 用户管理（users.html）
- 用户列表（分页，50条模拟数据）
- 搜索用户（用户名、手机号、邮箱）
- 状态过滤（正常/已封禁）
- 查看用户详情：基本信息、数据统计、用户偏好
- 封禁/解封用户

## 交互特性

### 已实现的交互

1. **响应式设计**：适配桌面端和移动端
2. **状态管理**：使用 localStorage 存储临时数据
3. **加载动画**：模拟异步操作（延迟 800ms-1.5s）
4. **消息提示**：成功/错误/信息提示（Toast）
5. **模态框**：表单提交、详情查看
6. **分页导航**：支持翻页和页码跳转
7. **数据过滤**：搜索、分类、状态筛选
8. **表单验证**：必填项、日期范围验证

### 模拟功能

以下功能在原型中通过前端逻辑模拟：

- LLM 对话回复（基于关键词匹配）
- 数据持久化（使用 localStorage）
- 热度计算（静态数值）
- 用户偏好提取（固定文本）
- 图表展示（占位符）

## 技术说明

### 技术栈

- **HTML5**：语义化标签
- **CSS3**：Flexbox、Grid、动画、渐变
- **JavaScript（ES6+）**：原生 JS，无框架依赖

### 设计规范

- **颜色主题**：
  - 主色：`#667eea`（紫色）到 `#764ba2`（渐变）
  - 背景：`#f5f7fa`（浅灰）
  - 文字：`#333`（深灰）、`#666`（中灰）、`#999`（浅灰）

- **圆角**：8px（卡片）、12px（模态框）、4px（按钮）
- **阴影**：`0 2px 8px rgba(0,0,0,0.08)`
- **间距**：8px、12px、16px、20px、24px

### 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 核心交互流程演示

### 流程 1：浏览景点并加入计划

1. 打开 `c-end/home.html`
2. 浏览热度排行或使用分类筛选
3. 点击景点卡片进入详情页
4. 点击"加入旅游计划"按钮
5. 前往"我的计划"查看

### 流程 2：智能对话规划行程

1. 点击右下角悬浮按钮进入对话
2. 输入："我想五月去北京玩三天"
3. 查看 AI 回复和推荐
4. 继续追问或选择快速操作

### 流程 3：管理景点信息

1. 打开 `b-end/attractions.html`
2. 使用搜索或分类过滤景点
3. 点击"添加景点"填写表单
4. 编辑或删除已有景点

## 注意事项

1. 本原型仅用于交互演示，不包含真实业务逻辑
2. 数据为模拟数据，刷新页面后部分操作会重置
3. 图片使用占位符或外部链接，网络异常可能无法显示
4. 建议使用 Chrome 浏览器获得最佳体验
