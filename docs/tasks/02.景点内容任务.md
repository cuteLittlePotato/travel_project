#### [M02-T01] C 端查询所需的 ORM 与 Repository

- 所属模块：M02 景点内容

- 依赖：M11-T01（景点/分类/地区表已建）
- 关联文档：数据库设计 §3.2
- 任务类型：后端

- 任务描述：实现 C 端只读查询所需的 Repository，含景点列表分页、按分类/城市筛选、详情聚合（含分类、交通）、热度读取。

- 交付物：
  - [x] `backend/app/modules/attraction/repository.py`
  - [x] `backend/app/modules/attraction/schemas.py` — C 端响应模型
  - [x] `backend/app/modules/attraction/service.py` — 响应组装与热度回退
  - [x] `backend/tests/unit/test_c_end_attraction_api.py` — 20 项

- 验收标准（DoD）：
  - [x] 列表查询仅返回 `is_published=true` 的景点（单测）
  - [x] 分类筛选为「且」关系（多分类同时满足）（单测）
  - [x] 热度值来自 `popularity_stat.final_popularity`，无记录时回退 `attraction.base_popularity`（单测）

- 边界与异常：分类表无数据时列表仍可正常返回；`popularity_stat` 关联缺失不导致 N+1 查询。

- **审查与修复（2026-11-09）**：

  本任务的代码在此前误入批次 3 时已写了一部分，本轮做了完整审查，
  发现并修复 4 个问题：

  1. **严重：`keyword` + `province_id` 同时传会 SQL 报错**
     原实现里两者各自 `join(Region)`，生成
     `FROM attraction JOIN region ... JOIN region ...`，
     PostgreSQL 报「table name "region" specified more than once」。
     而这恰恰是「搜索 + 按省筛选」这种最常见的组合。
     修复：join 提到条件判断之前，只 join 一次。
     **已加回归测试，并做了反向验证**——恢复旧代码后 3 项中 2 项立即失败。

  2. **`sort_by` 参数无校验**：未知值会静默回退到 `created_at`，
     用户以为按热度排、实际不是，且无从察觉。
     修复：白名单校验，越界抛 400。

  3. **重复方法**：`get_cities` 与 `get_parent_regions` 实现完全相同，
     合并为 `get_regions_bulk`。

  4. **`table_exists` 无用**：模块级函数，全项目无调用，已删除。

- **搜索建议包含省份**（用户确认）：
  搜「浙江」的用户想找的是整个省，只返回城市会漏掉这类意图。
  排序改为「前缀匹配优先 → 省份在前 → 权重降序」。

- 预估工时：2h
- 状态：DONE

#### [M02-T13] 景点浏览埋点

- 交付物：
  - [x] `backend/app/modules/recommend/event_recorder.py`
  - [x] `backend/app/api/middleware/auth.py::get_optional_user` — 可选认证
  - [x] 详情接口接入埋点
  - [x] `backend/tests/unit/test_event_recorder.py` — 11 项

- 验收标准（DoD）：
  - [x] 访问详情页产生 `event_type='view'` 记录（DB 断言）
  - [x] `popularity_stat.view_count` 递增（DB 断言）
  - [x] 埋点失败不影响主流程返回（接口测试：注入故障后仍 200）

- 边界与异常：未登录用户 `user_id` 为空仍需记录；高频写入需考虑异步化。

- **实现说明（2026-11-09）**：
  1. **新增 `get_optional_user` 可选认证依赖**：景点详情是公开接口，
     但登录用户应能记到自己名下。「坏 Token 不能让公开页面变 401」——
     本依赖**从不抛异常**，认证失败一律降级为匿名访问。有测试锁定。
  2. **埋点用独立 session + `create_task`**：不占用请求的数据库会话
     （那个会话在响应返回时就关了），也不让埋点耗时拖慢响应。
     持有任务引用防止被 GC 回收。
  3. **计数行用 `ON CONFLICT DO UPDATE`**：景点刚上线时
