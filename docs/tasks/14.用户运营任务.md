#### [M14-T01] 用户列表与详情接口

- 所属模块：M14 用户运营
- 优先级：P0
- 依赖：M01-T02
- 关联文档：API §13.1、§13.2、原型 `prototype/b-end/users.html`
- 任务类型：API

- 任务描述：实现 B 端用户列表（分页、搜索、状态筛选）与用户详情。

- 交付物：
  - [ ] `backend/app/api/v1/b_end/users.py`

- 验收标准（DoD）：
  - [ ] 列表含 `plan_count`/`footprint_count` 统计（结构断言）

- 边界与异常：已注销用户（`status='deleted'`）的展示与筛选。

#### [M14-T02] 用户封禁/解封接口

- 所属模块：M14 用户运营
- 优先级：P0
- 依赖：M14-T01, M01-T09
- 关联文档：API §13.3、§13.4
- 任务类型：API

- 任务描述：实现封禁与解封。封禁时使该用户所有 Token 失效。

- 交付物：
  - [ ] `backend/app/api/v1/b_end/users.py::ban` / `unban`

- 验收标准（DoD）：
  - [ ] 封禁后 `status='banned'` 且 `token_version` 自增（DB 断言）
  - [ ] 被封禁用户的原 Token 返回 401/403（接口测试）
  - [ ] 封禁操作写入 `operation_log`（DB 断言）（需求 §2.2.6）
  - [ ] 解封恢复 `status='active'`

- 边界与异常：重复封禁幂等；封禁原因长度限制 ≤200。

- 预估工时：1.5h
- 状态：TODO

#### [M14-T03] 用户分群统计接口

- 所属模块：M14 用户运营
- 优先级：P1
- 依赖：M14-T01
- 关联文档：API §13.5
- 任务类型：API

- 任务描述：实现用户分群统计（活跃/沉默/高价值）。

- 交付物：
  - [ ] `backend/app/api/v1/b_end/users.py::segments`

- 验收标准（DoD）：
  - [ ] 返回 `active_users` / `silent_users` / `high_value_users`（结构断言）
  - [ ] **活跃用户 = `user_event` 近 30 天去重用户数**（评审 §Q4 已确认）（单测）
  - [ ] **沉默用户 = 超过 90 天无登录**（`last_login_at`）（单测）
  - [ ] **`high_value_users` 返回 `null`**（MVP 暂不做）（结构断言）
  - [ ] 接口文档中说明 `active_users + silent_users ≠ total_users`（31~90 天为中间态）（文档检查）

- 边界与异常：总数为 0 时避免除零；`user_event` 为分区表，近 30 天查询需跨 2 个分区，注意性能。

- 预估工时：1h
- 状态：TODO
