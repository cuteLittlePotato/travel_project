#### [M15-T01] 系统管理表迁移与 ORM

- 所属模块：M15 系统管理
- 优先级：P0
- 依赖：M0-T13
- 关联文档：数据库设计 §3.9（admin_user / role / permission / role_permission / admin_user_role / operation_log / site_setting）
- 任务类型：DB迁移

- 任务描述：为七张表编写迁移与 ORM 模型。

- 交付物：
  - [ ] 迁移脚本
  - [ ] `backend/app/modules/system/models.py`

- 验收标准（DoD）：
  - [ ] `admin_user.token_version` 存在且默认 0（DB 断言）
  - [ ] `role_permission` 唯一约束 `(role_id, permission_id)`
  - [ ] `admin_user_role` 唯一约束 `(admin_user_id, role_id)`
  - [ ] `permission.action` CHECK 含 `create/read/update/delete/export/manage`
  - [ ] 规范检查：无物理外键；`site_setting.setting_key` 唯一

- 边界与异常：`admin_user` 与 `user` 完全分离（评审 §Q10）。

- 预估工时：1h

#### [M15-T02] 初始化数据（角色与权限项）

- 所属模块：M15 系统管理
- 优先级：P0
- 依赖：M15-T01
- 关联文档：评审 §Q13（权限数据驱动）、需求 §2.2.6
- 任务类型：DB迁移

- 任务描述：编写数据迁移，初始化两个角色（超级管理员 / 普通用户）与全部权限项（按「模块 × 操作」细粒度）。

- 交付物：
  - [ ] 数据迁移脚本
  - [ ] 权限项清单（覆盖 17 个模块的 CRUD）

- 验收标准（DoD）：
  - [ ] 初始化后 `role` 表有 2 条记录（DB 断言）
  - [ ] 权限项数量与模块数匹配（每模块至少 4 个 CRUD 权限）（DB 断言）
  - [ ] 超级管理员角色拥有全部权限（`role_permission` 记录数 = 权限总数）（DB 断言）
  - [ ] 规范检查：数据迁移可重复执行（幂等，`ON CONFLICT DO NOTHING`）
  - [ ] **规范检查：无物理外键（`grep -iE 'foreign key|references'` 无输出），对照 `docs/rules/database-rules.md` §4.2**

- 边界与异常：后续新增权限项时的增量迁移策略。

- 预估工时：1.5h
- 状态：TODO

#### [M15-T03] 管理员 CRUD 接口

- 所属模块：M15 系统管理
- 优先级：P0

- 关联文档：API §14.1 ~ §14.5
- 任务类型：API

- 任务描述：实现管理员的列表、创建、更新、重置密码、删除。

- 交付物：

- 验收标准（DoD）：
