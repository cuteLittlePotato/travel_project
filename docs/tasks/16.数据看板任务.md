#### [M16-T01] 看板查询服务骨架与刷新策略

- 所属模块：M16 数据看板
- 优先级：P0
- 依赖：M0-T02
- 关联文档：API §15.9、评审 §Q14（核心指标实时、趋势图每日）
- 任务类型：后端

- 任务描述：建立看板查询服务骨架，实现分层刷新策略：核心指标实时查询，趋势图走每日预计算表或缓存。

- 交付物：
  - [ ] `backend/app/modules/dashboard/service.py`
  - [ ] `backend/app/modules/dashboard/queries.py` — 各指标 SQL
  - [ ] `GET /api/v1/admin/dashboard/refresh-status`

- 验收标准（DoD）：
  - [ ] 刷新状态接口返回 `realtime_updated_at`/`daily_updated_at`（结构断言）
  - [ ] 核心指标查询走实时，趋势走缓存（代码审查 + 单测）
  - [ ] 规范检查：查询不得全表扫描（关键查询需有索引支撑，EXPLAIN 验证）

- 边界与异常：大数据量下的查询超时（限制时间范围）。

- 预估工时：2h
- 状态：TODO

#### [M16-T04] 业务指标接口

- 所属模块：M16 数据看板
- 优先级：P1
- 依赖：M16-T01, M04-T01
- 关联文档：API §15.3、评审 §Q14（完成率口径）
- 任务类型：API

- 任务描述：实现业务指标：计划创建/完成数、完成率、平均天数、平均预算、热门目的地。

- 交付物：
  - [ ] `backend/app/api/v1/b_end/dashboard.py::business_metrics`

- 验收标准（DoD）：
  - [ ] **`completion_rate = 已完成 ÷ (已完成 + 进行中 + 待进行)`，排除 `planning`**（评审 §Q14）（单测）
  - [ ] `top_destinations` 取前 10（单测）
  - [ ] 平均预算用 `AVG(budget_per_person)`（单测）
  - [ ] 接口返回 200 且字段结构符合 API §15.3（接口测试）

- 边界与异常：分母为 0 时完成率返回 0 而非 null。

- 预估工时：1.5h
