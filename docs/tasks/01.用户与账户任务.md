#### [M01-T03] 验证码发送与校验服务

- 所属模块：M01 用户与账户
- 优先级：P0
- 依赖：M01-T02, M0-T04
- 关联文档：API §3.1（发送验证码）、需求 §2.1.1
- 任务类型：后端

- 任务描述：实现验证码发送（短信/邮件）与校验服务。验证码存 Redis（DB 0），有效期 5 分钟。实现频率限制：同目标 60 秒 1 次、每日 5 次。

- 交付物：
  - [ ] `backend/app/modules/account/verification.py` — 生成、存储、校验、限流
  - [ ] `backend/app/infra/sms.py`、`backend/app/infra/email.py` — 短信/邮件发送封装（开发期可用 Mock）
  - [ ] Redis key 命名规范：`verify:{scene}:{target}`、`verify:rate:{target}`

- 验收标准（DoD）：
  - [ ] 60 秒内重复发送返回 `10003`（HTTP 429）（接口测试）
  - [ ] 每日超过 5 次返回 `10003`（单测）
  - [ ] 验证码错误或过期返回业务异常（单测）
  - [ ] 规范检查：验证码不在响应体中返回（序列化断言）

- 边界与异常：短信服务不可用时的降级与提示；同一验证码多次校验失败应作废；`scene` 枚举 `register/login/reset_password`。

- 预估工时：2h
- 状态：TODO
