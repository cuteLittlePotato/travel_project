#### [M12-T01] 模型与调用日志表迁移及 ORM

- 所属模块：M12 模型管理
- 优先级：P0
- 依赖：M0-T13
- 关联文档：数据库设计 §3.8（model / model_call_log）
- 任务类型：DB迁移

- 任务描述：为两张表编写迁移与 ORM 模型。`model_call_log` 为按月分区表，需创建初始分区。

- 交付物：
  - [ ] 迁移脚本
  - [ ] `backend/app/modules/model_gateway/models.py`
  - [ ] 分区维护任务（创建未来分区）

- 验收标准（DoD）：
  - [ ] `model` 唯一约束 `(category, model_code, base_url)`（DB 断言）
  - [ ] 部分唯一索引 `idx_model_default`（每类别一个默认）（索引存在断言）
  - [ ] `category` CHECK 含 `chat/vision/embedding/rerank/ocr`
  - [ ] `model_call_log` 为分区表，主键 `(id, created_at)`（表结构断言）
  - [ ] 规范检查：**无 `vector_dim` 字段**（维度由配置文件控制）（列存在性断言）
  - [ ] **规范检查：无物理外键（`grep -iE 'foreign key|references'` 无输出），对照 `docs/rules/database-rules.md` §4.2**

- 边界与异常：分区自动创建任务（每月前创建下月）；DEFAULT 分区兜底。

- 预估工时：1.5h
- 状态：TODO

#### [M12-T02] 模型 CRUD 接口

- 所属模块：M12 模型管理
- 优先级：P0
- 依赖：M12-T01
- 关联文档：API §10.1 ~ §10.4、原型 `prototype/b-end/models.html`
- 任务类型：API

- 任务描述：实现模型的列表、创建、详情、更新。`api_key` 加密存储。

- 交付物：
  - [ ] `backend/app/api/v1/b_end/models.py`
  - [ ] `backend/app/modules/model_gateway/service.py`
  - [ ] API Key 加解密工具（AES）

- 验收标准（DoD）：
  - [ ] 同类别下 `model_code + base_url` 重复返回 `22001`（409）（接口测试）
  - [ ] 创建时 `is_default=true` 自动取消同类别原默认（DB 断言）
  - [ ] **列表与详情不返回 `api_key_encrypted`**（序列化断言）
  - [ ] 更新时 `category` 不可修改，尝试修改返回 `22002`（400）（接口测试）
  - [ ] 规范检查：API Key 加密存储（DB 中非明文）（DB 断言）

- 边界与异常：`api_key` 不传保持原值、传空字符串清空（API §10.4）。

- 预估工时：2h

#### [M12-T05] 连通性测试接口

- 所属模块：M12 模型管理
- 优先级：P0
- 依赖：M12-T02, M06-T03
- 关联文档：API §10.8、需求 §2.2.5.6（分层校验）
- 任务类型：API

- 任务描述：实现连通性测试接口，分层校验：网络连通 → 鉴权 → 接口路径 → 响应格式 → 模型可用。不同类别使用不同测试请求。

- 交付物：
  - [ ] `backend/app/modules/model_gateway/connectivity.py`
  - [ ] 各类型的测试请求构造

- 验收标准（DoD）：
  - [ ] 五类模型各自的测试请求正确（单测，Mock LiteLLM）
  - [ ] 失败时返回分层结果（哪一层失败 + 原因）（结构断言）
  - [ ] 测试后更新 `last_test_at`/`last_test_ok`（DB 断言）
  - [ ] 规范检查：错误信息区分网络/鉴权/路径/格式/服务端（枚举覆盖测试）

- 边界与异常：超时时间配置化；测试不写入 `model_call_log`（避免污染统计）。
