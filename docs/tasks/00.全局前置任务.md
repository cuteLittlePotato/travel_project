#### [M0-T01] 后端工程骨架与配置中心

- 所属模块：M0 全局前置
- 优先级：P0
- 依赖：无
- 关联文档：架构 §4.2（后端目录结构）、`pyproject.toml` 现有依赖
- 任务类型：后端

- 任务描述：按架构文档 §4.2 建立后端目录骨架，实现基于 pydantic-settings 的配置中心，从环境变量加载全部配置项并做类型校验。建立 FastAPI 应用工厂与分层目录（core/api/modules/db/infra/tasks/schemas/utils）。

- 交付物：
  - [ ] `backend/app/main.py` — 应用工厂 `create_app()`
  - [ ] `backend/app/core/config.py` — Settings 类，覆盖 DB/Redis/Milvus/Neo4j/ES/MinIO/RabbitMQ/Langfuse/LiteLLM/地图/短信等全部配置项
  - [ ] `backend/app/core/deps.py` — 依赖注入占位
  - [ ] `backend/app/api/router.py` — 总路由注册
  - [ ] 目录骨架：`core/` `api/v1/{c_end,b_end}/` `modules/` `db/` `infra/` `tasks/` `schemas/` `utils/`
  - [ ] `backend/.env.example` — 环境变量模板（不含真实密钥）

- 验收标准（DoD）：
  - [ ] `uv run uvicorn app.main:app --reload` 可启动，访问 `/docs` 返回 200
  - [ ] 缺失必填配置时应用启动失败并给出明确字段名（可单测验证）
  - [ ] 规范检查：配置项命名遵循 `snake_case`；`.env.example` 不含任何真实密钥（`grep -iE 'password=.+|secret=.+|key=.{20,}' backend/.env.example` 无输出）

- 边界与异常：环境变量缺失、类型错误、非法端口值需在启动阶段明确报错，不允许静默使用默认值掩盖问题。

#### [M0-T02] 数据库连接与会话管理

- 所属模块：M0 全局前置
- 优先级：P0
- 依赖：M0-T01
- 关联文档：架构 §1.4、`docs/rules/database-rules.md`
- 任务类型：后端

- 任务描述：建立 PostgreSQL 异步连接（SQLAlchemy 2.x + asyncpg），实现会话管理与事务边界。定义 ORM Base 与通用字段约定（`id` UUID 主键、`created_at`/`updated_at` TIMESTAMPTZ）。**禁止在任何 ORM 模型中声明物理外键**。

- 交付物：
  - [ ] `backend/app/db/session.py` — async engine、SessionLocal、`get_db` 依赖
  - [ ] `backend/app/db/base.py` — DeclarativeBase、通用 Mixin（id/created_at/updated_at）
  - [ ] `backend/app/db/models/__init__.py` — 模型导出入口
  - [ ] `backend/app/db/migrations/` — Alembic 初始化配置

- 验收标准（DoD）：
  - [ ] 连接池可建立连接并执行 `SELECT 1`（集成测试）
  - [ ] **规范检查：`grep -rniE 'ForeignKey|relationship\(.*foreign_keys' backend/app/db/models/` 无输出**
  - [ ] Alembic `upgrade head` 与 `downgrade base` 可重复执行不报错
  - [ ] 主键类型统一为 UUID，命名统一为 `id`

- 所属模块：M0 全局前置
- 优先级：P0
- 依赖：M0-T01

- 任务类型：后端

- 任务描述：实现 `{code, message, data}` 统一响应封装与全局异常处理器。定义业务异常基类与错误码枚举，实现参数校验失败（10001）的字段级错误详情输出。

- 交付物：
  - [ ] `backend/app/core/response.py` — `success()/error()` 与响应模型
  - [ ] `backend/app/core/exceptions.py` — `BusinessError` 基类、错误码常量（按 API §1.7 分段）
  - [ ] `backend/app/core/error_handlers.py` — RequestValidationError、BusinessError、未捕获异常处理器
  - [ ] `backend/app/schemas/common.py` — 通用响应 Pydantic 模型
  - [ ] `backend/app/schemas/pagination.py` — 分页请求/响应模型

- 验收标准（DoD）：

#### [M0-T05] JWT 认证中间件与双端隔离

- 所属模块：M0 全局前置
- 优先级：P0
- 依赖：M0-T02, M0-T03
- 关联文档：API §1.2（认证方式）、API §16.3（权限校验矩阵）
- 任务类型：后端

- 任务描述：实现 JWT 签发与校验，Access Token 30 分钟、Refresh Token 7 天。载荷含 `user_type`（`user`/`admin`）与 `token_version`。实现双端隔离中间件：C 端 Token 不可访问 `/api/v1/admin/*`，反之亦然。

- 交付物：
  - [ ] `backend/app/core/security.py` — 签发/校验/刷新 Token，bcrypt 密码哈希
  - [ ] `backend/app/api/middleware/auth.py` — C 端认证依赖 `require_user()`
  - [ ] `backend/app/api/middleware/admin_auth.py` — B 端认证依赖 `require_admin()`
  - [ ] `token_version` 比对逻辑（对应用户表该字段）

- 验收标准（DoD）：
  - [ ] 无 Token 访问受保护接口返回 401 + `code=11001`（接口测试）
  - [ ] C 端 Token 访问 B 端接口返回 403（接口测试）
  - [ ] Token 中 `token_version` 与数据库不一致时返回 401（单测）
  - [ ] 规范检查：`password_hash`、`api_key` 等敏感字段在响应模型中不出现（序列化测试断言）

- 边界与异常：Token 过期、签名错误、载荷缺字段、算法混淆攻击（禁止 `alg=none`）均需覆盖测试。
