#### [M13-T02] 额度计量与判定服务

- 所属模块：M13 额度服务
- 优先级：P0
- 依赖：M13-T01, M0-T04
- 关联文档：需求 §2.2.5.8（双限：次数 + token）、评审 §Q5（覆盖范围）
- 任务类型：后端

- 任务描述：实现额度的实时计量与判定。Redis 原子递增计数，PG 存最终值。次数与 token 任一超限即拒绝。

- 交付物：
  - [ ] `backend/app/modules/quota/service.py` — `check_quota()` / `consume()`
  - [ ] Redis key 设计：`quota:{user_id}:{date}:calls`、`quota:{user_id}:{date}:tokens`

- 验收标准（DoD）：
  - [ ] 次数或 token 任一超限时返回拒绝（单测）
  - [ ] 判定使用 Redis 实时值，Redis 不可用时降级读 PG（单测）
  - [ ] **仅 `caller_type='user_chat'` 计入用户额度**（评审 §Q5）（单测）
  - [ ] 规范检查：原子递增使用 Redis `INCRBY`，非「读-改-写」（代码审查）

- 边界与异常：并发调用的额度超发防护；自然日边界（跨天时的清零）。

- 预估工时：2h
- 状态：TODO

#### [M13-T05] 额度同步与重置任务

- 所属模块：M13 额度服务
- 优先级：P0
- 依赖：M13-T02, M0-T07
- 关联文档：数据库设计 §5.1（PG 与 Redis 一致性）
- 任务类型：后端

- 任务描述：实现两个任务：定期将 Redis 计数同步到 `user_quota`（PG）；跨日时 Redis 计数自然过期（或显式重置）。

- 交付物：
  - [ ] `backend/app/tasks/schedule/quota_sync.py`

- 验收标准（DoD）：
  - [ ] Redis 计数定期同步至 PG（单测，Mock Redis）
  - [ ] Redis key 设置 TTL 至次日 00:00，自然过期实现重置（单测）
  - [ ] 同步幂等（重复执行不重复累加）（单测）

- 边界与异常：Redis 丢失时的恢复（以 PG 为准回填）；同步失败重试。
