#### [M04-T01] 计划相关表迁移与 ORM

- 所属模块：M04 旅游计划
- 优先级：P0
- 依赖：M0-T13
- 关联文档：数据库设计 §3.6（trip_plan / plan_candidate / plan_day / plan_activity）
- 任务类型：DB迁移

- 任务描述：为四张计划相关表编写迁移与 ORM 模型。注意 `plan_day` 挂 `candidate_id` 而非 `plan_id`（评审决策 Q3）。

- 交付物：
  - [ ] 迁移脚本
  - [ ] `backend/app/modules/trip_plan/models.py`

- 验收标准（DoD）：
  - [ ] `plan_day` 唯一约束为 `(candidate_id, day_number)`（索引断言）
  - [ ] `trip_plan.status` CHECK 含 `planning/pending/ongoing/completed/cancelled`
  - [ ] `plan_activity.activity_type` CHECK 含 `attraction/dining/transport/accommodation/rest`
  - [ ] `plan_activity` 有 `idx_planact_attraction` 索引（用于统计）（索引断言）
  - [ ] 规范检查：无物理外键；金额字段 `NUMERIC(12,2)`

- 边界与异常：`edit_lock_user` + `edit_lock_at` 实现编辑锁；`selected_candidate_id` 与 `plan_candidate.is_selected` 需保持一致。

- 预估工时：1h

#### [M04-T08] 计划状态自动流转定时任务

- 所属模块：M04 旅游计划
- 优先级：P1
- 依赖：M04-T07, M0-T07
- 关联文档：API §6.16、需求 §2.1.4
- 任务类型：后端

- 任务描述：每日 00:05 执行的 Celery Beat 任务：`pending` → `ongoing`（到达 `start_date`）；`ongoing` 且已过 `end_date` 时生成「提醒确认完成」通知。

- 交付物：
  - [ ] `backend/app/tasks/schedule/plan_status.py`

- 验收标准（DoD）：
  - [ ] 到达出发日的 `pending` 计划自动变为 `ongoing`（单测，使用冻结时间）
  - [ ] 已过结束日的 `ongoing` 计划生成 `plan_ended` 通知（DB 断言）
  - [ ] 任务幂等：重复执行不重复生成通知（单测）

- 边界与异常：时区处理统一 Asia/Shanghai；批量更新需分批避免长事务。

- 预估工时：1.5h
- 状态：TODO
