#### [M03-T01] 会话与消息表迁移及 ORM

- 所属模块：M03 对话交互

- 关联文档：数据库设计 §3.5（chat_session / chat_message / chat_pending_interaction / agent_checkpoint）
- 任务类型：DB迁移

- 任务描述：为四张对话相关表编写迁移与 ORM 模型。

- 交付物：
  - [ ] 迁移脚本（含 `chat_session`、`chat_message`、`chat_pending_interaction`、`agent_checkpoint`）

- 验收标准（DoD）：

- 边界与异常：`chat_session.working_memory` 为 JSONB；`message_count` 为冗余字段需与消息表保持一致。

#### [M03-T04] 消息发送接口（SSE 流式，骨架）

- 所属模块：M03 对话交互
- 优先级：P0
- 依赖：M03-T03, M06-T01
- 关联文档：API §5.4
- 任务类型：API

- 任务描述：实现 `POST /api/v1/chat/sessions/{id}/messages` 返回 `text/event-stream`。连接前校验登录、会话归属、额度；将请求委托给 M06 Agent 引擎并转发事件流。

- 交付物：
  - [ ] `backend/app/api/v1/c_end/chat.py::send_message`
  - [ ] M06 的调用接口 `agent_service.run_stream(...)`

- 验收标准（DoD）：
  - [ ] 未登录返回 401、会话不存在 404、额度超限 429（均不建立 SSE）（接口测试）
  - [ ] 正常请求返回 `Content-Type: text/event-stream`（接口测试）
  - [ ] 用户消息与助手回复均落库 `chat_message`（DB 断言）
  - [ ] 规范检查：响应头含 `Cache-Control: no-cache`、`X-Accel-Buffering: no`

- 边界与异常：流式过程中异常需以 `error` 事件推送后关闭；客户端断开时保存已生成内容。

- 预估工时：2h
- 状态：TODO

#### [M03-T05] 待处理交互表与提交接口

- 所属模块：M03 对话交互
- 优先级：P0
- 依赖：M03-T01, M03-T04
- 关联文档：API §5.5、评审 §17.4（SSE 超时后的恢复机制）
- 任务类型：API

- 任务描述：实现 `POST /api/v1/chat/sessions/{id}/interactions/{interaction_id}` 提交用户选择。四种 `interaction_type` 的 `answer` 结构校验。

- 验收标准（DoD）：
